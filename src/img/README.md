# Product Images

Please place your product images in this folder with the following names:

- **product1.png** - Moringa Leaf Powder product image
- **product2.png** - Ashwagandha Powder product image  
- **product3.png** - Tulsi Leaf Powder product image

## Image Requirements

- **Format:** PNG (with transparent background recommended) or JPG
- **Recommended Size:** 800x800 pixels or higher
- **Aspect Ratio:** Square (1:1) or portrait for best results
- **File Size:** Optimized for web (under 500KB recommended)

## Notes

- Images will be displayed in a smooth infinite carousel slider
- They will automatically scale to fit the container while maintaining aspect ratio
- Make sure the images have consistent styling for a professional look
